# DataViz Pro 📊

Interactive data visualization tool. Upload CSV files, get instant insights with charts and statistics.

![React](https://img.shields.io/badge/React-18.0-blue)
![Chart.js](https://img.shields.io/badge/Chart.js-Latest-green)

## Features

- 📤 CSV file upload (drag & drop)
- 📊 Auto-generate charts (Bar, Line, Pie)
- 📈 Statistical analysis (mean, median, min, max)
- 📋 Data table with pagination
- 🎨 Green/teal gradient theme

## Tech Stack

**Frontend:** React, Chart.js, PapaParse  
**Styling:** CSS3 with gradients

## Installation
```bash
git clone https://github.com/Ishita2520/dataviz-pro.git
cd dataviz-pro
npm install
npm run dev
```

Open http://localhost:5173

## Usage

1. Click "Download Sample CSV" or upload your own
2. View automatic statistical analysis
3. Customize charts (type, X-axis, Y-axis)
4. Explore data table with pagination
